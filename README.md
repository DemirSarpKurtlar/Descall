# Descall

**Friends. Voice. Video. Chat.**

[descall.com](https://descall.com) · [Download Windows Setup](https://github.com/DemirSarpKurtlar/Descall/releases/latest/download/Descall-Setup-2.9.22.exe) · [Releases](https://github.com/DemirSarpKurtlar/Descall/releases)
