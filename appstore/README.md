# App Store listing (com.descall.app)

Pushed to App Store Connect by `.github/workflows/appstore-metadata.yml` (manual `workflow_dispatch`) using `asc_metadata.py`, which calls the App Store Connect API directly.

| File | What it is |
|---|---|
| `metadata.json` | TR (primary) + en-US name, subtitle, promo, description, keywords, What's New, plus URLs, copyright and category. It's generated by the listing build script (`appstore-listing/_build/metadata.py`), which asserts Apple's limits and the banned-word list. Don't edit it by hand. |
| `age-rating.json` | Age rating questionnaire answers (13+ via Social Media = Yes) |
| `review-notes.txt` | App Review notes; the `{{DEMO_*}}` placeholders are filled from repo secrets at run time (limit 4000 chars) |
| `screenshots/iphone69/` | iPhone 6.9" (1320×2868) → `APP_IPHONE_67`, used for both locales |
| `screenshots/ipad13/` | iPad 13" (2064×2752) → `APP_IPAD_PRO_3GEN_129`, used for both locales |

Inputs: `mode` (`verify` = read-only report, default; `apply` = write the listing, rename the rejected/editable version, attach the build, replace screenshots, never submits; `submit` = read-only verify, then submit for review with manual release only if verify has no errors or warnings, needs `build`), `version` (default = `frontend/package.json`), `build` (exact build number), `wait_build_minutes`.

Secrets: `ASC_KEY_P8`, `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_DEMO_USERNAME`, `ASC_DEMO_PASSWORD`, `ASC_DEMO_B_USERNAME`, `ASC_DEMO_B_PASSWORD`, `ASC_REVIEW_PHONE`.

The API can't set the App Privacy "nutrition label"; that has to be done in the App Store Connect web UI. Keep it identical to `frontend/ios/App/App/PrivacyInfo.xcprivacy`.
