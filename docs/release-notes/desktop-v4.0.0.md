# Descall masaüstü 4.0.0 (yeni Windows uygulaması)

Yeni, çok daha hafif Windows uygulamasının ilk sürümü.

- Daha küçük kurulum, daha az bellek, daha hızlı açılış.
- Yeni ekran paylaşımı: Descall'ın kendi sesi paylaşıma hiç girmiyor, yani izleyenler aramanın sesini geri duymuyor. Oyun ve video sesi paylaşılıyor.
- 60 fps paylaşım 144 Hz ve üzeri monitörlerde de kare kaybetmeden akıyor.
- Paylaşılan pencere kapanınca paylaşım hemen bitiyor; HDR ekranlarda soluk görüntü yok.
- Güncellemeler imzalı geliyor ve kurulmadan önce doğrulanıyor.
