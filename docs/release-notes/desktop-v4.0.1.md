# Descall masaüstü 4.0.1 (yeni Windows uygulaması)

- Düzeltme: uygulama bazı bilgisayarlarda tasarımsız (stiller yüklenmeden) açılıyordu. Artık her açılışta tam görünümüyle açılıyor.
- Yeni ekran paylaşımı: Descall'ın kendi sesi paylaşıma hiç girmiyor; oyun ve video sesi paylaşılıyor; 60 fps paylaşım 144 Hz ve üzeri monitörlerde kare kaybetmeden akıyor.
- Güncellemeler imzalı geliyor ve kurulmadan önce doğrulanıyor.
