# Descall masaüstü 4.1.3

- Görev çubuğuna küçültülen pencere, görev çubuğundaki Descall düğmesine tıklayınca yeniden açılıyor.
- Güncellemeden sonra küçültülmüş başlayan pencere, küçültünce görev çubuğundan kaybolmuyor.
- Başlık çubuğuna sağ tıklayınca açılan pencere menüsü, kapandıktan sonra Geri Yükle ve Ekranı Kapla komutlarını kapalı bırakmıyor.
