# Descall masaüstü 4.1.2

- Yeni envanter: kuşanmadan önce canlı önizlemeyle dene, "Uygula" deyince herkes görsün; geri alma, kayıtlı görünümler, kuşanma geçmişi ve rastgele kombin.
- Mağazada setler arasında oklarla, noktalarla ve klavyeyle geçiş; kategori satırı fare tekerleğiyle kayıyor.
- Aynı anda iki sesli kanala bağlı kalma sorunu giderildi; sesli kanal ile arama aynı anda açık kalmıyor.
- Arama kartı yalnızca Descall arka plandayken görünüyor.
- Satın alma, set paneli ve hediye ekranında düzeltmeler.
