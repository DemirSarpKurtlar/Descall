# Descall masaüstü 4.1.1

- Bas-konuş: tuşa basılıyken başka pencereye geçince ya da tuşları farklı sırayla bırakınca mikrofon artık açık kalmıyor.
- Güncellemeden veya "Yeniden başlat"tan sonra pencere tepsiye gizlenmiyor, bıraktığın gibi geri geliyor.
- Görev çubuğunda tek Descall düğmesi var; açılırken kısayola tekrar tıklamak pencereyi getiriyor.
- Tepsideyken açık sohbete gelen mesajlar sen bakana kadar okunmamış kalıyor.
- Tepsiden Çık dediğinde yazdığın taslak kaybolmuyor.
- Uygulama arka plandayken açılan mağaza, menüler ve bildirimler artık görünmez kalmıyor.
- Windows 11'de büyüt düğmesinin üzerinde bekleyince Snap düzenleri açılıyor. Alt+Boşluk ve Alt+F4 çalışıyor.
- Büyük ekran görüntüsü yapıştırınca uygulama donmuyor; tepsideyken daha az bellek kullanıyor.
- Kapalıyken tıklanan bildirim doğru sohbeti açıyor.
- Güncellemeler daha sağlam; güvenlik ve gizlilik iyileştirmeleri.
