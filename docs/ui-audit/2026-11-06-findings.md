You are a senior product designer + frontend engineer working on **Descall**, a Discord-like voice/chat app (web React, Electron desktop, iOS). Repo: DemirSarpKurtlar/Descall.

An app-wide UI audit found 157 places that look inconsistent with the rest of the app or look "AI-generated". Fix them following these rules:

**Design rules (mandatory)**
- Brand palette: dark base #1B1D26, surface #393C4D, accent logo-blue #587AF5. No Discord blurple (88,101,242), no random green/purple gradients, no mesh/aurora blobs, no decorative emoji in UI copy.
- Follow Apple fluid-interface principles: instant press feedback, interruptible springs, size-specific typography, reduced-motion support.
- Every menu/sheet/popover/modal = heavy frosted glass (strong blur + high-opacity tinted base). Never see-through.
- All UI copy is Turkish, informal "sen" form. No English leftovers.
- Use the existing design tokens/components; don't invent one-off styles. Consistent radii, spacing, icon set and font weights across screens.
- Don't add anything about AI assistants, call recording, or Valorant/Riot/LFG.
- Don't change DB schema, payments/DesCoin logic or business behavior: this is visual/UX only.

**How to work**
1. Start with the YÜKSEK (high) items, then ORTA, then DÜŞÜK.
2. For each item: find the location, apply the fix, make sure it works on web, Electron and mobile widths (375px+) in dark and light theme.
3. Group fixes into small, reviewable PRs by area. Run tests; never hide failures.
4. Report per item: done / skipped (why).
