## Cursor Cloud specific instructions

### Auth
- Descall uses **custom JWT** (`JWT_SECRET`); Supabase is DB/storage only (service role), not Supabase Auth.
- Google Sign-In: GIS ID token → `POST /auth/google` → same app JWT. Requires `GOOGLE_CLIENT_ID` (and ideally `VITE_GOOGLE_CLIENT_ID` at frontend build). If client ID is missing, the UI shows “not configured” and password auth still works.
- Before Google login works end-to-end, apply `supabase/migrations/20260729_add_google_oauth_columns.sql` (adds `email`, `google_id`, `auth_provider`; makes `password_hash` nullable).
- Google-only accounts have `password_hash = null`; password login returns a message to use Google.
- **iOS keyboard vs composer (2.9.196):** WKWebView often does not shrink the visual viewport, so the message field stays under the keys. `DescallBridgeViewController` publishes the web-view overlap via `window.__descallNativeKeyboard(px)`. `mobileViewportBox` lifts by `max(visual gap, native inset)` and does not add them. Test: `node frontend/src/lib/mobileViewport.selftest.mjs`.
- **iOS session token (2.9.194):** the JWT lives in the Keychain (`DescallKeychainPlugin`, ThisDeviceOnly, after first unlock). `getToken()` stays synchronous. `main.jsx` `await hydrateSecureToken()` copies Keychain → memory before the session check and before render. First launch migrates `localStorage` `descall_token` once, then deletes it. A missing plugin or a 1.5s timeout keeps localStorage. Web, Android, and Electron are unchanged (Electron still uses `safeStorage`). Test: `node frontend/src/lib/secureToken.selftest.mjs`.
- **Boot never hangs (2.11.7):** `index.html` keeps exactly one `#boot-splash` on every platform (the app-shell safety net injects one before the static markup is parsed; two used to stack and the top one, which no dismiss/failure ever touched, was the Electron "stuck on the splash"). Main (`electron/bootWatchdog.cjs`): splash `loadFile` raced at 5s, main-frame `did-fail-load` retried 1/3/8s then a native Tekrar dene / Çıkış dialog, renderer crash during boot reloads (max 2), window revealed after 15s even without `ready-to-show`. - **Inline-script CSP on Windows (2.11.11):** Chromium hashes inline `<script>` text after HTML input preprocessing (CRLF / lone CR → LF). `electron/cspPolicy.cjs` and `scripts/csp-sync-lib.mjs` normalize newlines before hashing; `.gitattributes` (`* text=auto eol=lf`) keeps every checkout LF, and `release.yml` refuses a CRLF `index.html` and stops on a failing `npm ci` / `build:prod` (pwsh did not stop on a failing csp-verify-dist, so 2.11.2–2.11.10 shipped Windows builds where every inline script was blocked and the splash never left). Script assets are never inlined as `data:` (`assetsInlineLimit`, the noise-gate worklet). CSP also allows `*.googleusercontent.com` images and PostHog `eu-assets` / gtag scripts (web + Electron). Packaged boot smoke: `Descall.exe --descall-smoke-boot` (`electron/bootSmoke.cjs`, exit 0 only when React mounted, splash gone, inline scripts ran, none blocked); release runs it on the Windows build, PR CI on a CRLF Linux build. ### Voice / group calls

- **Electron paint watchdog and deep-route reloads (2.13.1):** main's paint watchdog (`bootWatchdog.cjs`) arms only on a main-frame, cross-document navigation (`did-start-navigation`, `shouldArmPaintWatchdog`); `did-start-loading` also fires for React Router `pushState`, so 2.11.9–2.13.0 re-armed it on every in-app navigation and "clean reloaded" a healthy app 22 s later (seen as Mağaza → Ülkeler dropping to the splash). - **Electron update vs voice (desktop only):** a downloaded update still installs on real quit (`autoInstallOnAppQuit`). It does **not** `quitAndInstall` during a DM call (incoming / outgoing / active), group call (including incoming ring), or server voice/stage channel (including connecting). The renderer reports `voice:set-busy` over the preload bridge; main also treats the voice overlay as busy and **resets busy on renderer crash, reload, and window close** (default not-busy, so a dead renderer cannot block updates forever). After the user leaves every call, main waits **2 minutes** (`CALL_GRACE_MS`) and re-checks busy immediately before install — a call that starts during the grace cancels it. Otherwise a pending update applies when the session is locked or input has been idle for **5 minutes**, or (only if this update never overlapped a call) after the window has been in the background for **12 seconds**. Explicit Restart / tray “Güncelle ve Çık” during a call asks first (TR/EN `updateToast.confirm*`). Web and iOS never load the bridge. Decision tests: `node frontend/electron/updateDeferral.selftest.mjs`, `node frontend/src/lib/voiceBusy.selftest.mjs`.

- **Screen share (DES-10):** desktop `getDisplayMedia` **omits** `displaySurface` by default so the full OS picker (window / entire screen / tab) appears — locking `"browser"` made many users only see the Descall tab. Remotes classify with `classifyInboundMedia` (LiveKit source, track name, signaled stream id, transceiver mid, `displaySurface`). Do not treat “a share is expected” or arrival order as identity; that published the camera as the share and skipped a display track that arrived with system audio. DM sends **one** explicit offer carrying `screen` `{streamId, videoMid, audioMid}` (`screen:share-start` carries the same). Screen/tab audio stays off the mic element and off the voice tuner (`collectScreenAudioTrackIds`; Opus switches to music when a `screen-audio` sender is present). ### UI conventions
- **No emojis in the UI (owner rule):** never use emoji characters as icons, labels, bullets, status glyphs or decoration in any user-facing surface (components, i18n strings, toasts, menus, empty states, buttons). They render inconsistently across platforms (Windows flag/emoji gaps) and read as "AI-made". Use the app's icon packs instead: `@phosphor-icons/react` via `components/ui/Icon.jsx` (the shared wrapper) and the existing custom icon components (`TemplateIcon`, `SpecialBadgeIcon`, `CountryFlag`, etc.). The only sanctioned non-icon glyphs are the country **flag** code points, which already go through `CountryFlag` + the bundled Twemoji flag font (`installFlagFont`). When a new glyph is needed and no icon exists, add/import a Phosphor icon, don't paste an emoji. This also applies to scratch/repro HTML that might be mistaken for app code.
